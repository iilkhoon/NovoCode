# Portfolio playbook
- Bold personality: oversized name/headline, distinctive font, one signature visual idea (marquee, large numbers, cursor-following highlight — tastefully).
- Sections: intro, selected work (grid with hover reveal, opens detail modal), about with photo, skills/services, experience timeline, testimonials, contact form → `db.collection("messages")`.
- Gallery images with consistent aspect ratios; lazy loading.
